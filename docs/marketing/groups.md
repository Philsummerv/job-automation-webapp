# Group tracker

Fill this in the day you join, while the About page is still open. Day 4 (the
admin DM) and Day 5 (the post) both depend on the `Promo?` and `Admin` columns,
and going back to re-derive them for eight groups is an hour you won't want to
spend.

**Promo?** — from the group's own Rules tab, not a guess:
- `yes` — self-promo allowed, sometimes on a specific day. Note the day.
- `ask` — rules say ask an admin first. These are the best ones.
- `no` — links or promo banned outright. **Do not skip these groups.** They are
  still worth your time via the reply play; you just never post a link.

**Status** — `joined` → `warming` (commenting, days 2–4) → `asked` (admin DM'd)
→ `posted` / `declined`.
